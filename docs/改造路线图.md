## 0. 给执行 Agent 的执行须知（必读）

### 0.1 执行纪律

1. **一次只做一个 Task**。完成 → 跑验收命令 → 贴出命令真实输出 → 再进入下一个。
2. **禁止一次性重构多个模块**。每个 Task 的改动范围已在下方锁定，不得越界。
3. **每个 Task 完成后必须跑该 Task 的"验收命令"**，验收不通过不得标记完成，不得靠"看起来对了"下结论。
4. **不得为了让测试通过而修改测试断言**。若测试失败，先在文档中记录真实报错，再判断是代码问题还是测试过时。
5. **PowerShell 是本项目的历史雷区**（见 `bad.md` #6/#14/#18）：修改含中文的文件时，**禁用 `apply_patch` 多行补丁**，改用编辑器工具直接写入；任何字符串替换后必须用 `rg` 复核命中数。
6. **改完后端任何路由/服务代码，必须重启 uvicorn 进程**（`bad.md` #12/#16 两次事故根因）。无 `--reload` 时必须手动重启并实测接口。

### 任务卡 P0-3：修复 CORS_ORIGINS 启动崩溃

**依赖**：无
**涉及文件**：`backend/app/core/config.py`、`backend/app/main.py`、`.env.example`、`backend/.env.example`

**背景**：D-7。**已实测复现**：`Settings(CORS_ORIGINS='a,b')` 抛 `SettingsError`。

**已验证的修复方案（必须用方案 A）**：

> 实测结论：`@field_validator(mode="before")` **无效** —— pydantic-settings v2 的 `EnvSettingsSource` 在校验器运行**之前**就对复杂类型做 JSON 解析并抛错。

**方案 A（采用）**：字段声明为 `str`，另加 property。

```python
# backend/app/core/config.py
# 1) 修改字段声明
CORS_ORIGINS: str = (
    "http://localhost:5173,http://localhost:5174,http://localhost:5175,"
    "http://localhost:5176,http://localhost:5177,http://localhost:5178,"
    "http://localhost:5179,http://localhost:3000,"
    "http://127.0.0.1:5173,http://127.0.0.1:5175"
)

# 2) 新增 property（放在 Settings 类内）
@property
def cors_origins(self) -> list[str]:
    """逗号分隔的 CORS 白名单 → list"""
    return [o.strip() for o in self.CORS_ORIGINS.split(",") if o.strip()]
```

```python
# backend/app/main.py
# 3) 修改中间件引用
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,   # 原为 settings.CORS_ORIGINS
    ...
)
```

**同时**：`.env.example` 中 `CORS_ORIGINS=http://localhost:5173,http://localhost:80` 保持逗号格式即可（方案 A 兼容）。

**搜索确认无其他引用点**：
```bash
rg -n "CORS_ORIGINS" backend/ --glob '!*.pyc'
```

**验收命令**：
```bash
cd E:/job3.0/backend
CORS_ORIGINS="http://localhost:5173,http://a.com" ./.venv/Scripts/python.exe -c "
from app.core.config import settings
print('解析成功:', settings.cors_origins)
assert settings.cors_origins == ['http://localhost:5173','http://a.com']
print('OK')
"
./.venv/Scripts/python.exe -m pytest tests/ -q 2>&1 | tail -3   # 期望：57 passed
```

**禁止事项**：不要删除 CORS 配置。不要改成 `allow_origins=["*"]`（与 `allow_credentials=True` 组合是安全反模式）。

### 任务卡 P2-1：真 RAG（检索 + 引用溯源）

**依赖**：P1-4

**设计规格**：

1. **存储**：用 `sqlite-vec` 扩展复用现有 SQLite，**不要引入独立向量库进程**（保持零运维）。
   ```
   pip install sqlite-vec
   ```

4. **检索**：向量 Top-K（K=5）+ 关键词 BM25 混合召回，RRF 融合排序
5. **引用溯源**（这是 D-1 承诺的核心）：
   - 响应新增 `sources: [{doc_id, title, chunk_index, snippet, score}]`
   - 前端在 AI 回复下方渲染引用角标，点击展开原文片段
